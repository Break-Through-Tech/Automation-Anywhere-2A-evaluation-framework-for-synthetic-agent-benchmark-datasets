# Optional experiments

These experiments are separate from the supplied synthetic benchmark and the
primary evaluation framework.

`onboarding_pilot/` provides a revised six-scenario banking onboarding environment
and outcome grader. Its fixtures include authored assumptions. Its tests live
alongside the experiment, and saved results are in
`results/experiments/onboarding_state_v1/`.

See the pilot README for offline validation and saved-state regrading commands.
Historical source snapshots remain with its results so relocation does not
replace the original run's provenance.
