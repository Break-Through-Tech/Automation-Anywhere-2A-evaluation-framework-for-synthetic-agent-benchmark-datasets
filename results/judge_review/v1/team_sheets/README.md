# Team review sheets

Claim one linked issue and review its four primary attempts independently. No coding is required. Instructions, evidence excerpts, full-trace links, and an answer template are included in each issue.

Groups 2 and 4 also contain one optional shared case for checking reviewer agreement. These sheets support an initial review; detailed milestone labels may require follow-up.
